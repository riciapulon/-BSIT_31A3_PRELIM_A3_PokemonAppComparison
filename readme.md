The homepage starts with a Pokémon-themed background, and after searching, the background updates with the searched Pokémon’s image at 80% opacity. 
The Pokémon’s name and description are centered, semi-transparent, and styled with a font similar to the Pokémon logo. 
JavaScript fetches Pokémon data from the PokéAPI and dynamically updates the UI. 
The background overlay ensures visibility, and the Live Server in VS Code helps display changes smoothly.
